## 操作順序
1. 以 **ChatGPT Work 模式** 開啟官方已登入 ChatGPT 頁面，核對側邊欄目標專案精確名稱 `YOUTUBE CD HUD`。
2. 先搜尋 P0：`Selected component properties` / `Panel text size` / `recovery/cdj-modular-20261009` / `feature/studio-floating-shell-20261012` / `f06d8f8` / `live-preview-fix` / `feature/live-monitor-visual-composer-mvp`。
3. **每一筆**記錄原始標題、完整 `https://chatgpt.com/c/...` URL（或原生可見之專案內聊天 URL）、當前來源專案、對話內實際主題、是否混合。用 URL 去重，不能用日期/摘要推斷為唯一聊天。
4. 只對純專案、權限合格、無既有專案來源疑慮的聊天點選「移至專案」；來源已在其他專案時先依 `SKILL.md` 的來源保護規則進入 `review-needed`，不可直接搬移。涉及 TUNNAL、Lead Agent Control Plane、跨專案的聊天一律保留原處，建立引用。
5. 在目標專案重新開啟、核實 **相同 URL**，留下證據描述及檢查時間，才寫入 `verified`；找不到或 UI 無權限用 `blocked` / `not-found` / `review-needed`，不可虛構。
