# 面板編輯器

## 操作流程

1. 在「面板排版」內的主題工具列選擇全功能、精簡或隱形提示版，調整主題色與輔色。
   展開文字設定後，可選字體、輸入本機字體名稱及像素字級。
   字體來自本機，找不到時使用等寬字體替代。
2. 點選畫布元件，或使用元件選單選取。選單也包含完全透明的元件。
   寬高使用 CSS 像素；數字欄位向上進位為整數，例如 120.2 → 121 px。
   預覽區維持固定高度、不顯示捲動條，可拖右下角調整區域大小。
   元件以實際 CSS 像素大小顯示，不隨工作區縮放。拖曳空白處可平移視野，
   「置中面板」可返回中央；從元件選單選取時會將該元件置中。
3. 展開選取元件的詳細設定，調整底色、文字、圖層與效果。
   詳細設定每次載入頁面時預設收合；展開後，調整設定與切換元件皆維持
   展開，直到手動收合或關閉頁面。
   每個元件都有獨立的「不顯示」選項，保留位置與色彩設定。底色、輔色
   （邊框及效果）與文字色可分別調整不透明度；色彩透明不等於隱藏元件。
4. 方向鍵移動 1 像素、Shift＋方向鍵移動 10 像素、Delete 移回元件庫，
   Enter 切換該元件的鎖定狀態。鍵盤操作僅作用於取得焦點的畫布元件。
5. 「儲存並套用」會保存排版並鎖定整體面板；按旁邊的 UNLOCK 後可再次編輯。
   個別元件的 LOCK 狀態會保留。A／B／C 是瀏覽器工作階段儲存槽；
   「儲存並套用」才會將作用中的面板持續保存在本機。

底座不能移除，可獨立調整尺寸。所有已加入的元件，包括分離的兩個跳曲
按鈕，都必須有部分區域與底座重疊。超出限制的移動與縮放會被拒絕。
群組縮放遇到尺寸上下限、碰撞、脫離底座或鎖定時，會保留整份原排版。
縮放全部元件時，底座也會同步縮放；縮放後若已有其他編輯，無法再使用
該次縮放的 UNDO，以保留後續修改。

## 面板程式碼

最下方可顯示目前面板的 JSON；先載入儲存槽，就能匯出該面板。
貼上完整程式碼後按「從程式碼產生面板」即可預覽，再儲存並套用。
輸入無效時會保留目前排版。此功能取代原本的自訂 CSS 編輯與套用功能。
JSON 只作為資料解析，不執行其中的 JavaScript 或 CSS。

## 實際 HUD 與驗證

HUD 使用固定 CSS 像素，不隨播放器解析度縮放。當面板大於播放器時，
部分區域可能超出可見範圍，可選較小版型或縮小尺寸。
作業系統縮放與瀏覽器縮放仍會影響 CSS 像素對應的實體螢幕像素。

LOCK／UNLOCK 只用於設定頁排版，不在 YouTube 顯示。
排版時，解鎖元件後可直接拖曳邊緣移動；使用把手或 ALT＋邊緣拖曳調整大小。
拖動底座會移動整組面板；開啟對齊時，整組位移會吸附格線，儲存後仍維持相對位置。
編輯器鎖定狀態保護個別元件的排版操作。
正式使用時，從底座空白處或任何元件邊緣拖曳，都會移動整組面板（包含拆分控制），
元件的相對位置與尺寸維持不變。唱片中央保留播放定位，按鈕中央保留原有功能。
正式面板的位置與元件座標分開保存，可在播放器內移動，不受編輯畫布座標限制。

唱盤提供整體不透明度：0% 透明、100% 不透明，會一起影響圖像、底色與邊框。
底色不透明度另行保存，顯示時會與整體不透明度疊乘；兩者均可隨排版保存及匯出。
DB 來源選單設有 240 px 最小寬度；窄畫面時以視窗可用寬度
為限，選項文字可換行完整顯示。
儲存面板或 A／B／C 儲存槽時，會檢查選單按鈕的層級，必要時移到可見元件最上層；
正式使用時，展開選單也會將所屬按鈕暫時置頂。

文字字級滑桿的左半段為 8–32 px，右半段為 32–192 px。
每個文字元件另提供 100–900 字重調整（400 標準、700 粗體）。瀏覽器使用
該字型支援的最接近字重，不合成假粗體。字重會保存在排版與匯出 JSON 中；
未指定字重的舊排版維持各元件的預設粗細。

底座、文字與按鈕的最小高度為 24 px，唱片最小直徑為 24 px，曲目清單最小
高度為 48 px。大字級或格線對齊仍可能需要更高的元件；編輯器與 YouTube HUD
採用相同限制。編輯器的鎖定標記與解鎖按鈕以紅字呈現，面板內容維持設定的文字色。
儲存或鎖定會維持設定的配色，不再疊加深淺遮罩。
全功能、精簡、隱形提示三個內建面板使用既有的元件底色、文字色與不透明度。
全功能與精簡使用不透明灰色底座與深灰控制區；隱形提示保留透明底座。

自動測試涵蓋 JSON 往返、鎖定、鍵盤微調、底座接觸、縮放與執行階段投影。
設定頁可視驗收及 YouTube／Tampermonkey 實機驗收仍須人工確認。
