# 介面語言

Chrome 擴充功能介面提供繁體中文（台灣）、英文與日文，包含設定頁，以及 HUD 的已翻譯控制項、狀態訊息與無障礙標籤。語言偏好會和其他擴充功能設定一同保存在本機，因此手動選擇會保留在目前的 Chrome 使用者設定檔中。

本文件說明目前已實作的擴充功能行為；不宣稱 Userscript 或實際 YouTube 工作階段已完成實機瀏覽器驗收。

## 選擇語言

1. 開啟 YouTube CD HUD 擴充功能的設定頁。
2. 在「介面語言」選擇「自動偵測」、「繁體中文（台灣）」、「English」或「日本語」。
3. 儲存設定。

選擇「自動偵測」時，介面會依瀏覽器偏好的語言清單決定顯示語言。選擇指定語言後，即使稍後變更瀏覽器語言，介面仍會維持該指定語言。

## 自動偵測與回退規則

自動模式會依序檢查瀏覽器提供的偏好語言（`navigator.languages`）。

| 瀏覽器語言比對 | 設定頁語言 |
| --- | --- |
| 以 `zh` 開頭的語言 | 繁體中文（台灣），`zh-TW` |
| 以 `en` 開頭的語言 | 英文，`en` |
| 以 `ja` 開頭的語言 | 日文，`ja` |
| 沒有支援或可用的比對 | 繁體中文（台灣），`zh-TW` |

例如，`zh-Hant`、`zh-TW` 與其他 `zh-*` 偏好都會使用繁體中文（台灣）介面。遺失、不支援或格式不正確的已儲存選項會回到「自動偵測」，再依相同規則回退。

擴充功能只讀取瀏覽器提供的語言偏好；不會變更 Chrome 或作業系統的語言設定。

## 儲存設定與適用範圍

這項選擇會以 `language` 欄位儲存在 `chrome.storage.local` 的既有 `ytCdHudSettings` 記錄中，預設值為 `auto`。使用既有本機設定記錄，因此設定會保留在目前的使用者設定檔，並遵循擴充功能既有的儲存與重設行為。

本次翻譯包含擴充功能設定頁，以及 HUD 的可見控制項與狀態文字。資料來源名稱、指令、CSS 選擇器、路徑、`YT` 與 `1001` 等來源識別碼，以及使用者輸入的自訂 CSS 都維持不變。

## 給貢獻者

支援的持久化值為 `auto`、`zh-TW`、`en` 與 `ja`。使用語言值前請先正規化；僅能從瀏覽器偏好清單解析 `auto`。請維持 `zh-TW` 回退值，讓缺少或不支援的瀏覽器偏好仍能完整顯示設定介面。

新增擴充功能介面的可見文字時，請同步加入三份語言目錄，並保留介面依賴的 HTML、欄位識別碼、指令與 CSS 選擇器。修改實作檔案後執行：

```powershell
npm run check
npm test
```

這些本機檢查不取代 Chrome、Tampermonkey 與 YouTube 的可見實機驗收。
