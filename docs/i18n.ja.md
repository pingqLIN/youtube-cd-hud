# インターフェース言語

Chrome 拡張機能のインターフェースは、繁体字中国語（台湾）、英語、日本語に対応しています。設定ページに加え、HUD の翻訳済みコントロール、状態メッセージ、アクセシビリティラベルも対象です。言語設定は他の拡張機能設定とともにローカルに保存されるため、手動で選んだ言語は現在の Chrome プロファイルに保持されます。

この文書は、実装済みの拡張機能の動作を説明するものです。Userscript または実際の YouTube セッションについて、ブラウザーでの受け入れ確認が完了したとは主張しません。

## 言語を選ぶ

1. YouTube CD HUD 拡張機能の設定ページを開きます。
2. 「インターフェース言語」で「自動検出」、「繁體中文（台灣）」、「English」、または「日本語」を選びます。
3. 設定を保存します。

「自動検出」を選ぶと、ブラウザーの優先言語リストに従って表示言語を決定します。個別の言語を選ぶと、その後にブラウザー言語を変更しても選択した言語が維持されます。

## 自動検出とフォールバック

自動モードでは、ブラウザーが提供する優先言語を順に確認します（`navigator.languages`）。

| ブラウザー言語の一致 | 設定ページの言語 |
| --- | --- |
| `zh` で始まる言語 | 繁体字中国語（台湾）、`zh-TW` |
| `en` で始まる言語 | 英語、`en` |
| `ja` で始まる言語 | 日本語、`ja` |
| 対応する一致がない、または取得できない | 繁体字中国語（台湾）、`zh-TW` |

たとえば、`zh-Hant`、`zh-TW`、その他の `zh-*` 言語設定では、繁体字中国語（台湾）の画面を使用します。保存済みの値が欠落している、未対応である、または形式が不正な場合は「自動検出」に戻り、同じ規則でフォールバックします。

拡張機能はブラウザーから提供された言語設定を読むだけで、Chrome またはオペレーティングシステムの言語設定を変更しません。

## 保存される設定と適用範囲

この選択は、`chrome.storage.local` にある既存の `ytCdHudSettings` レコードの `language` フィールドとして保存されます。既定値は `auto` です。既存のローカル設定レコードを使うため、設定は現在のプロファイル内に保持され、拡張機能の既存の保存・リセット動作に従います。

今回の翻訳範囲には、拡張機能の設定ページと、HUD の表示コントロールおよび状態テキストが含まれます。プロバイダー名、コマンド、CSS セレクター、パス、`YT` や `1001` などのソース識別子、利用者が入力したカスタム CSS は変更しません。

## コントリビューター向け

保存可能な値は `auto`、`zh-TW`、`en`、`ja` です。言語値は使用前に正規化し、`auto` はブラウザーの優先言語リストだけから解決してください。対応しない、または取得できないブラウザー言語でも設定ページを完全に表示できるよう、フォールバックは `zh-TW` のままにします。

拡張機能のインターフェースに表示する文字列を追加するときは、3 つすべての言語カタログに追加し、インターフェースが利用する HTML、フィールド識別子、コマンド、CSS セレクターを維持してください。実装ファイルを変更した後は、次を実行します。

```powershell
npm run check
npm test
```

これらのローカル検証は、Chrome、Tampermonkey、YouTube で表示を確認する受け入れテストの代わりにはなりません。
